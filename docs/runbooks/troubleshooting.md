# Dépannage

## Méthode

```text
Symptôme
   ↓
Reproduire
   ↓
Isoler
   ↓
Tester la couche physique
   ↓
Tester réseau / système
   ↓
Tester logiciel
   ↓
Corriger
   ↓
Documenter
```

## Règle

Ne pas modifier plusieurs variables simultanément lorsqu'il est possible de tester une hypothèse isolée.

## Après résolution

Ajouter :

- symptôme
- cause
- solution
- prévention éventuelle
