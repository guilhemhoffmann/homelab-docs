# Focusrite

## Rôle

Interface audio principale.

## Connexions

| Port | Destination | Usage |
|---|---|---|
| USB | Ordinateur | Audio / contrôle |
| IN 1 | À renseigner | Instrument |
| IN 2 | À renseigner | Instrument |
| OUT 1-2 | À renseigner | Monitoring |

## Dépannage

Si des crépitements apparaissent :

1. vérifier le câble USB ;
2. vérifier l'alimentation ;
3. vérifier le buffer audio ;
4. tester sans hub USB ;
5. redémarrer l'interface ;
6. vérifier les logs / pilotes.
